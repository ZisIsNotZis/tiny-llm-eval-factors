**Reading:** quantisation is not uniformly damaging. The multi-turn agentic task retains only a small fraction of its Q3 score at Q2, while single-function code and single-turn tool calls retain much more. The longer the horizon and the more state the task carries, the more a low-quant model loses — which is exactly what short, single-function benchmarks cannot measure, and the practical basis for the community's Q4/Q5 recommendations.
