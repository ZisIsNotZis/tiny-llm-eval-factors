# 结论（唯一结论集）

所有量化结论都是**家族内对照**，用**有效位宽**，CI 按**题目级** SE。原始数据在 `experiments.sqlite`，
可读版本见 `report.html`。本节不重复任何原始数据表。

## F1 —— Q2→Q3 在绝大多数家族为正，从不显著为负

同一 Q2→Q3 步长在 7 个基准上同向复现，中位步长：GSM8K +0.460、HumanEval+ +0.409、IFEval +0.250、
MBPP+ +0.235、MMLU +0.146、ARC-Challenge +0.100、TruthfulQA +0.005。顺序即 F9 的顺序。
步长大小取决于"Q2 是否真的伤了这个模型"：granite-4.1-3b +0.344、gemma-4-E2B +0.215，
而 Qwen3.6-35B-A3B +0.037（Q2 时已 ~0.70）。**仅在显著为负**从未出现。

## F2 —— 量化曲线是"先阶跃、后平台"

Qwen3.5-2B（MultiPL-E，家族内）：IQ2_XXS ~0.006（崩），IQ2_M 0.139 ≈ Q2 0.120，
**Q2→Q3 +0.155 [+0.107,+0.204]**，随后 Q3→Q4 +0.008、Q4→Q5 −0.006（CI 跨 0）。
**操作规则：至少 Q3；Q3 以上除非能测出具体收益，否则多花比特买不到分数**（granite 是个例外：Q3→Q4 +0.078 显著）。

## F3 —— Q2 是"地板塌陷"，不是线性衰减

2B 在 Q2 时，BFCL 困难多轮类别全部钉在 ~0.005（base 0.025 / miss_param 0.005 / long_context 0.005 / miss_func 0.005），
Q3 各自回到天花板（0.185 / 0.105 / 0.110 / 0.080）。**损失不是一个常数**（不同任务 0.077–0.202，取决于剩余 headroom）；
真正稳定的是这个地板——小模型在困难 agentic 任务上 Q2 整体崩掉。

## F4 —— 方案 > 位数；厂商标签为 null

文件大小几乎相同时，换**方案**（IQ 系列 vs K 系列）分数有差：2B IQ3_XXS vs Q2_K_XL **+0.065 [+0.009,+0.121]**，
4B +0.047，合并 **+0.056 [+0.008,+0.104]**。而换**厂商**（bartowski vs unsloth，大小差 0.6%）为 null
（+0.009 [−0.058,+0.077]）。**比字节/方案，不比厂商标签。**

## F5 —— 三元/亚2bit 是"配方特定"，不是"三元定律"

Ternary-Bonsai-27B（~2.25 bpw）在同权重配方上可媲美常规 2.9–3.9 bpw（多轮 0.695/0.675，登顶）。
但同一"三元"标签换到 GLM-4.7-Flash-UD-TQ1_0 上只有它自己 Q2 的一半（cpp 0.236 vs 0.472）。→ 是模型/配方特性。

## F6 —— 多数"常调的旋钮"其实惰性

| 轴 | 结果 |
|---|---|
| KV-Cache 量化 | f16 / q8_0 / q4_0 无可测差异（MMLU 0.6096/0.6075/0.6140；GSM8K/IFEval/HumanEval 都在一个题目级 SE 内） |
| `top_k` @ temp 0 | 完全惰性（K∈{1,40,200} 逐位相同）——这是结构事实：temp 0 没有分布可截断 |
| `top_k` @ temp 0.3 | K∈{20,40,64} 几乎不变（161 题里只变 2–4 题）；只有 K=1 会动 |
| 温度 | 压低代码分（HumanEval 0.573→0.512），但 **MMLU 逐位不变**（走对数似然，不采样）——正控制，证明测量链路正确 |
| flash-attn | Q3 无操作，Q2 有真实影响（regime-dependent） |
| MTP 草稿深度 | 速度轴（见 F10）；草稿在 gemma 上未启用过（`m52`，非 null） |

## F7 —— PPL 是弱代理，不能作决策依据

PPL 与任务分在约 30% 情况方向相反，且能两边都错：LFM2.5-8B-A1B PPL −2.9% 而分数 −0.022；
gemma-4-E2B PPL +13.9% 而分数翻倍（0.201→0.416）。Q3 以上 PPL 继续降而 pass@1 已平台。

## F8 —— 协议选择会翻转量化结论的符号（两次）

Qwen3.5-9B 的 Q2→Q3：聊天/思考下 −0.073，而 MultiPL-E 原始补全 +0.143。
Qwen3.5-4B 工具调用：强制 JSON 提示 vs 原生 `tools=` 结论不同。→ **任何量化结论都必须写明协议。**

## F9 —— 量化伤害依赖基准：敏感性是一个"向量"（头条）

每 +1 有效位宽的中位斜率：GSM8K +0.156、IFEval +0.117、HumanEval+ +0.104、MBPP+ +0.065、
MMLU +0.054、ARC-c +0.026、TruthfulQA +0.014 —— **约 11 倍跨度**。
家族内配对检验：能力型组（代码+指令+推理）− 知识型组（MMLU+ARC+TruthfulQA）
= **+0.12/bpw，95% CI [+0.04,+0.20]**，n≈18 家族，多数同向。
含义：需要精确格式输出的任务（能编译的函数、合规的指令回答、规范格式的数字）先崩；
四选一/判断真假的知识题最后崩，因而是**判断量化最差的基准**。

## F10 —— 投机解码（MTP）只加速，不伤质量

草稿深度 0/1/2/4：0.8B +36%、4B +83%、9B +93% tok/s（模型越大收益越大）。
质量侧：**MMLU 在每个模型每个深度逐位相同**（对数似然路径不走草稿）——正控制；可动的列（GSM8K/IFEval/HumanEval）
都在一个题目级 SE 内、无一致符号。**注意**：该轴只在 `-MTP-GGUF` 仓库上跑得动，是不同 checkpoint 家族。

## F11 —— MoE 里决定分数的是"非专家层"

同一 LFM2.5-8B-A1B base，只改"哪些层拿低比特"：均匀 Q3_K_M（3.88 bpw）HumanEval+ 0.335 / MMLU 0.447；
专家 IQ2/Q2 其余 Q5（2.92 bpw）0.287 / 0.427；专家 Q4_K 其余 Q2_K（**4.48 bpw，比特最多**）**0.134 / 0.287，最差**。
原因：非专家层（注意力、归一化等）每个 token 每次前向都用，单个专家只有部分 token 走到。→ **保护非专家层，专家层是省比特的安全区。**

## F12 —— 量化感知训练（QAT）在同比特下没有质量红利

同标称 `UD-Q?_K_XL` 下 QAT 文件小 0.36–0.95 bpw。5 个可跑配对（12B Q4、E2B Q2/Q4、E4B Q2/Q4）：
**所有 Q4 配对与原生测不出差别**（且小 0.44–0.95 bpw）；Q2 配对 QAT 明显更差（E2B：HE+ −0.31、GSM8K −0.29、IFEval −0.17；
E4B：HE+ −0.17、MBPP+ −0.21、MMLU −0.15、GSM8K −0.39）。→ **QAT 是"更小体积"选项，不是质量升级。**
元数据事实：QAT 文件是 `file_type=2`（Q4_0 血统），原生是真 K-quant，所以差值还混了"方案"这一项。

## F13 —— GSQ-RCO 方案在匹配有效位宽下没有优势

固定 Qwen3.8-27B，GSQ-RCO IQ3_XXS(3.058) / IQ3_S(3.549) 对原生阶梯，同时比"最近档位"和"按位宽插值"：
**全部 28 个差值的 95% CI 都跨 0**。→ 方案红利不普适（对照 F4）。

## 实用选择建议

1. 默认 **≥ Q3**；Q3 以上除非能测出收益否则不必多花比特（granite 例外）。
2. 代码/推理/指令是"早期预警"；知识类基准（MMLU/TruthfulQA）最后才掉，别用它判断量化够不够。
3. 小模型做 agentic 长任务要更多余量：2B 在 Q2 会整体崩。
4. 同文件大小时方案可能比档位更关键（IQ > K），但厂商标签不重要——比字节，不比标签。
5. 别用 PPL 决策。
6. 别指望 QAT 挽回量化损失；它只是同配方更小的体积。
7. 换协议后必须重测（协议会翻号）。

| 曾主张 | 现状 | 原因 |

| LFM2.5-8B-A1B Q3<Q2 显著 | **改为测不出** | 用了跨语言 CI（n=2），窄约 10 倍 |

| "Q2→Q3 收益恒为 +0.15" | **修正** | 6 个格子过度概括（4B 单轮仅 +0.077） |
| "损伤随任务长度放大" | **撤回** | retention-ratio 假象 |

| 12B 原生 Q4 MMLU 0.644 | **存疑待复测** | 仅 MMLU 异常，其它基准对不上 |

## 旧版遗留结论（早期小样本，低于噪声地板者只作假设）

- 结构性打分模型 `pred = 1 − exp(−raw)`（带 size/act/quant 饱和帽）：分布内与同家族新 checkpoint 上优于线性 ridge，
  但**一旦 held-out 整个架构就被 ridge 反超**（family RMSE 0.294 vs 0.282）。预测器不可用；价值在受控效应与负结果。
- 推理关闭相对开启的分数差很大（HumanEval +0.62、MBPP +0.52），但幅度由 Qwen3.6 主导，是**家族条件性**的。
- 长上下文单侧 KV：某 27B 在 ctx=24576 时 V 侧量化比 K 侧退化更重（单点、低普适性）。
- 早期 QAT 证据符号混合（E4B HE 升、MBPP 降）——已被大规模 F12 取代。
- 全因子墙钟模型：`log1p(wall) ~ 全因子` 岭回归，CV RMSE(log) 0.311（~36% 乘性误差）。
