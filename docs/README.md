# 本地模型设置选择对基准分数的影响 —— 研究文档（唯一的文档来源）

## 这是什么项目

**问题：给本地部署的大模型换各种设置（setting）之后，它在基准上的实际跑分会怎么变？**

这里的"设置"是一个很宽的集合，量化只是其中**一个**子项：

- 量化相关：权重量化位宽、量化方案/厂商、量化感知训练（QAT）、第三方方案（GSQ-RCO）、三元/低位宽；
- 模型本身：模型规模（参数量）、模型类型（dense / MoE）、MoE 各层的比特分配；
- 推理运行时：KV 缓存精度、采样参数（温度/top_k）、思考开关（reasoning）；
- 解码方式：投机解码（MTP）草稿深度、扩散式解码。

**每个设置就是一项研究**：把它当作自变量 **X**，基准分数当作因变量 **Y**。所有比较都在**同一个模型家族内部**进行
（同一套 base 权重，只换设置），因此架构与参数量天然固定，X 是唯一在变的东西。

**量化位宽这一项**另有一条硬规则：横轴必须用真实**有效位宽**（`8 × 文件字节数 ÷ 参数量`），
**绝不使用 Q2/Q3 这类标称标签**——同名标签在不同模型上实际跨度 2.76–5.04 比特/权重，没有可比性。见 `NAMING.md`。

## SSOT：每个事实只有一个家

| 内容 | 唯一归属 | 说明 |
|---|---|---|
| 测量数字 | `experiments.sqlite` | 结果只在这里；报告/表格都由它生成 |
| 名字、术语、**禁用词** | `docs/NAMING.md` | 例如"禁止用 Q2/Q3 当量化标签" |
| 项目定位与研究范围 | `docs/README.md`（本文件） | 报告标题与概述必须与本文件一致 |
| 研究方法与规则 | `docs/METHOD.md` | |
| 报告呈现规范 | `docs/REPORTING.md` | 表格形状、总-分-总、中文、图例等 |
| 结论（客观实验） | `docs/L2-结果.md` | 只写测出来的事实 |
| 结论（agent 派生） | `docs/L3-分析.md` | 只写推断/建议 |
| 运维 / 数据库 / 待办 | `docs/OPERATIONS.md`、`docs/DATABASE.md`、`docs/BACKLOG.md` | |
| 项目规则（harness 用） | `AGENTS.md` | |

**派生物不定知识：** `report.html` 是由 `make_report.py` 从数据库生成的**视图**——它的数字只能来自数据库，
它的措辞必须服从本目录文档，且**不得引入文档里没有的新论断**（结论在 `docs/L2-结果.md`）。

**一致性规则（本项目的纪律）：** 同一个事实不得在两个文件里各说一套；文档之间、以及报告与文档之间
不得冲突。例如：若 `NAMING.md` 禁止 Q2/Q3 标签，则 `L2-结果.md` 与报告里也不得用 Q2/Q3 作为量化档的说法。
发现冲突时，先改"家"，再让派生物跟上。

## 文档分层（不同来源不得混写）

| 层 | 含义 | 文件 |
|---|---|---|
| **L0 用户要求** | 用户给出的要求 / guide（最高优先） | `L0-要求.md`、`REPORTING.md` |
| **L1 客观规范/事实** | 方法、名字、协议、环境、数据库规则 | `NAMING.md`、`METHOD.md`、`DATABASE.md`、`OPERATIONS.md` |
| **L2 客观实验结论** | 测出来的事实（带来源/run_tag） | `L2-结果.md` |
| **L3 agent 派生结论** | 由 agent 推断的解释与建议 | `L3-分析.md` |
| 规划 | 尚未跑的假设与硬阻塞 | `BACKLOG.md` |
| 本文件 | 索引与 SSOT 规则 | `README.md` |

## 当前规模（以数据库为准）

- `experiments.sqlite`：约 3300 行（已去重）、208 个模型文件、59 种协议。
- 标准基准：代码（HumanEval+、MBPP+）、知识（MMLU）、科学（ARC-Challenge）、事实性（TruthfulQA）、
  推理（GSM8K）、指令（IFEval）。

## 如何复现

```sh
python3 make_report.py        # 从数据库生成 report.html（唯一的报告视图）
python3 .wrapup/mktables.py   # 打印每张结构化表的行数与覆盖（不写文件）
python3 migrate_db.py         # 入库（唯一入库路径；只跑一次，跑完校验 总行数==distinct）
python3 check_consistency.py  # 一致性门：检查文档/报告是否违反禁用词或彼此冲突
```
