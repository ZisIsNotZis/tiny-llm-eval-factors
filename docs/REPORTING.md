# 写报告的规范（operator 已锁定，按此执行）

## 唯一的报告 = 生成的 `report.html`

- 报告由 `python3 make_report.py` 从 `experiments.sqlite` **直接生成**，禁止手改。
- **禁止解析 markdown 当数据源**；禁止维护"同一份数据的另一种格式"（如 `RESULTS_BY_COMPARISON.md` 这类副本已被删除）。
- 表格结构来自 `.wrapup/mktables.py` 的 `build_tables()`（只读 DB，返回结构化表）。

## 表格形状：一个变量一张表

1. 每张表只回答**一个**研究变量 X；两个变量不合表，一个变量不拆表。
2. 表内：**第 1 列 = 被固定住的组（series）**，**第 2 列 = 变化的变量 X**，其余列 = 每个基准一列。
3. **列永不筛选**：某个基准这一轴全空也要保留这一列。
4. 行只按两条过滤：**整行没有任何基准值**则删；**某第 1 列组里 X 不足 2 个取值**（无可比）则删。其余一律保留。
5. 单元格：`分数 (n)`，括号是题目数（可据此复算题目级 SE）；缺失写 `—` 或 `无结果`，**绝不写 0**。

## 报告结构：总—分—总

1. **总（开头）**：说明这个研究要回答什么、X/Y/series 的定义、数据规模。
2. **分（每一项一节）**：每节 = 中文标题 + 该研究一句话说明 + 它的 X/Y 原始数据表 + **它自己的图**。
3. **总（结尾）**：**显著性回顾**——一张表把每项归成"显著 / 测不出（不显著）/ 未测"。

## 语言与命名

- 正文用**中文人话**，不用翻译腔（不要"敏感性是向量"这类；要"同一个量化步长在不同基准上损失差别很大"）。
- 量化二字必须出现；不用只有内行才懂的缩写当标题。
- 基准名等专有名词保留（MMLU、HumanEval 等），但列名用中文（如"知识 MMLU"）。
- 显著性呈现：**红色 = 该 95% 置信区间不跨 0**。

## 图

- **每项研究都有自己的图**，从 DB 现画（`make_report.py` 内生成到 `figures/report/`）。
- 图内中文需注册 CJK 字体（`Noto Sans CJK`），否则出方块。
- 图要大（满宽），不做幼教式讲解。

## 复算口径

- 题目级标准误 `SE = √(p(1−p)/n)`；两分数差 `SE_diff = √(SE₁²+SE₂²)`；95% CI = 差值 ± 1.96·SE_diff。
- `无结果`/`BLOCKED`/`GATE-FAIL` 是显式非测量，不是 0。
