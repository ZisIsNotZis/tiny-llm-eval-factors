# L2 —— 客观实验结论（测出来的）

> 层级：**L2 客观实验结论**。只记录从测量得到的事实；每条注明来源（`run_tag` 或报告中的表/图）。
> 解释、判断、建议、与其它结论的关系一律放在 `L3-分析.md`，不写在这里。
> 量化一律用**有效位宽**（比特/权重）表述，**不使用 Q2/Q3 等标称档位**。

## 权重量化位宽

- 同一模型家族内，从较低比特档到下一档（各家族实际跨度不同，典型约 0.8–1.7 比特/权重），
  7 个标准基准上的分数普遍上升。来源：各家族量化阶梯，见报告「量化位宽」节的表与图。
- 按基准汇总的该步长中位数（越大=该基准对位宽越敏感）：推理 GSM8K +0.460、代码 HumanEval+ +0.409、
  指令 IFEval +0.250、代码 MBPP+ +0.235、知识 MMLU +0.146、科学 ARC-c +0.100、事实性 TruthfulQA +0.005。
- 每个基准"每 +1 比特/权重 的分数变化"中位数：推理 GSM8K +0.156、指令 IFEval +0.117、代码 HumanEval+ +0.104、
  代码 MBPP+ +0.065、知识 MMLU +0.054、科学 ARC-c +0.026、事实性 TruthfulQA +0.014（约 11 倍跨度）。
- 家族内配对差（能力型：代码+指令+推理）−（知识型：MMLU+ARC+TruthfulQA）= **+0.12 / 比特，
  95% CI [+0.04, +0.20]**，多数家族同向。
- Qwen3.5-2B 的多语言代码（有效位宽 → 分数）：3.27→0.0062、3.66→0.1387、3.96→0.1894、4.11→0.0920、
  4.93→0.2184、5.70→0.2836、6.24→0.2774。来源：报告表 A（来自数据库）。

## 模型规模

- 同一量化配方下，参数量越大分数越高；小模型之间的差距通常大于大模型之间。

## 量化方案 / 厂商

- 文件字节接近时，换方案（IQ 系列 vs K 系列）分数有差：2B 约 +0.065、4B 约 +0.047，合并约 +0.056
  （95% CI [+0.008,+0.104]）。来源：报告表 C / 图。
- 换厂商标签（同一模型、大小差 <1%）测不出差异（约 +0.009，95% CI [−0.058,+0.077]）。

## MoE 各层比特分配

- 同一套 base 权重，只改"哪些层拿低比特"：均匀 3.88 比特/权重 → HumanEval+ 0.335 / MMLU 0.447；
  专家层压到 IQ2/Q2、其余层高位（2.92 比特/权重）→ 0.287 / 0.427；
  专家层用 Q4_K、其余层压到 Q2_K（4.48 比特/权重，比特最多）→ **0.134 / 0.287（最差）**。

## KV 缓存精度

- f16 / q8_0 / q4_0 三种 KV 精度在短上下文（约 1–2k tokens）下分数无可测差异。长上下文未覆盖。

## 采样 / 解码参数

- 温度从 0 升到 0.3/0.7 会压低代码通过率；温度 0 时 top_k 无影响；MMLU 对采样完全无反应（走对数似然）。

## 思考开关 / 投机解码

- 投机解码：草稿深度越大速度越快（0.8B 约 +36%、9B 约 +93%）；分数随深度几乎不变，MMLU 在每个深度逐位相同。
- 思考开关：开/关对 GSM8K 的差随模型与预算而定；小预算下开思考更低。

## 量化感知训练（QAT）

- 同标称配方下 QAT 文件小 0.36–0.95 比特/权重。所有 4-bit 档配对里，QAT 与原生在多数基准测不出差异；
  12B 配对的 MMLU 例外：差值 −0.197（95% CI [−0.242,−0.153]，显著为负），且该原生档位本身存疑。
- 低位宽（约 2-bit）档配对里 QAT 明显更低：E2B 代码 −0.31 / GSM8K −0.29 / 指令 −0.17；
  E4B 代码 −0.17 / MBPP −0.21 / MMLU −0.15 / GSM8K −0.39。

## 第三方方案（GSQ-RCO）

- 固定 Qwen3.8-27B，GSQ-RCO 的两个档（3.058 / 3.549 比特/权重）对原生阶梯（2.878 / 3.850 / 4.173），
  与"最近原生档"或"按位宽插值后的原生"比较，所有差值的 95% CI 都跨 0。
