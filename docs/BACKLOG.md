## 尚未跑的假设

- **B1 三元/极低位宽的"异常点"**：三元（Bonsai）与 `Q1`/`Q2` 可能根本不在平滑"更多比特→更高分"的曲线上
  （要么异常好，要么断崖）。已有部分结果（F5），剩余：`Q2_0` 加载失败需查（SHA 已排除截断）；
  `PQ2_0`（ggml type 142）需更新的 llama.cpp；同模型内的干净方案对照。用**匹配比特/权重**（非匹配量化名）比较。
- **B2 厂商推荐采样参数**：unsloth 给每个模型发布推荐运行/采样参数；我们固定协议。做一次受控检查：
  用厂商推荐采样会不会改变任何量化结论（即我们的协议是否是 confound）。
- **B3 跨家族多轮**：BFCL 多轮只在一个锚点（Qwen3.5-2B）跑过。扩到 granite/gemma/MoE 锚点，
  及其它多轮类别（miss_func / miss_param / long_context）。
- **B2(MoE 激活参数) 双变量回归**：模型规模应写成 `score = f(总参数量, 激活参数量)` 的联合回归，
  因为没有"同家族同总参、不同激活"的受控样本，激活轴不能单列。
- **Tier 1A 专家级/逐张量 MoE 量化**：需要 F16 源（~70 GB）。
