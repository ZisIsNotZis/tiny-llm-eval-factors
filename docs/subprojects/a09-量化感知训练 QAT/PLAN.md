## 判定口径（先写死，避免事后挑解释）

1. **X = 该量化文件是否经过 QAT 训练**；Y = 各基准分数。位宽归 `a01`，量化方案归 `a03`，层比特分配归 `a04`，采样归 `a06`；本轴只把它们当**混杂变量**并在结论里钉住或标注。
2. **标称配方不是比特预算**：`UD-Q4_K_XL` 只是配方名。每份文件的比特预算取 gguf 头的实测 bits/参数（`8 × 文件字节 ÷ 参数数` 与「按张量 offset 差算的数据段位宽」互相校验，差 >0.05 就打 WARN），分配轮廓按张量类别（`attn / embed / ffn-dense / output / norm`）读，复用 `a03` 的 `analysis/alloc.py`。
3. **配对只在一族内**：一族 = 去掉 `-qat`/`-it`/`-ud` 后的同一 base 权重的血统根名（保留尺寸，大小写不敏感）。跨族同字节点不是受控比较。
4. **配对前先验协议**：`protocol` 逐列相等（本轴的规范协议取 `a01::curves.BENCH`），`n_items` 相等；不等即该格「不可比」并打印，不进任何汇总。
5. **区间 = 两比例差的 Newcombe method 10**，复用 `a01::curves.newcombe_diff`；`truthfulqa_mc2` 的 `acc` 是概率质量均值（`i01::res26`），那一列只报差值不套二项区间。区间是非配对的（逐题结果没落库），所以「跨 0」只能说测不出。
6. **不池化**：基准、族、协议之间绝不平均。跨族汇总只用「同号族数 + 逐族区间」，并打印参与汇总的族数。
7. **12B 异常只用它自己那一族的阶梯判**：`gemma-4-12b` 的原生阶梯 mmlu 有三个同协议点（Q2/Q3/Q4）。允许段内线性插值到 QAT 的实测比特，外推单独标注；不允许拿别的族、别的基准的斜率代替，也不允许拿「常识上 12B 应该多少」当判据。
8. **未测 ≠ 0**：没测的格写「未测」+ 原因 + 代价；缺的一侧不画成 0 分。
9. **单次运行**：所有配对都是单次运行，区间只含逐题二项项。库内有两条同文件同协议的重复测量（`m78`/`m119`、`m80`/`m121`，8 个基准逐格相同），这是「同输入重跑同结果」的旁证，不是跨 run 区间的替代。
