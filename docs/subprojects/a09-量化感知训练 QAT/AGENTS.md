# a09 量化感知训练 QAT — 本目录规则

本文件只写这个 subproject 自己的窄规则；通用法则在仓库根 `AGENTS.md` 与 `/home/z/vibe/AGENTS.md`，不在此复述。
里程碑、工作包、AC、判据与派工在 `PLAN.md`；已成立的事实与证据在 `RESULT.md`；复算装置是 `analysis/qat_pairs.py`。

## 这个轴的口径（违反一条，结论就作废）

1. **X 只有「这份 gguf 是否经过 QAT 训练」。** 位宽归 `a01`、方案与厂商标签归 `a03`、层比特分配归 `a04`、采样归 `a06`。本轴拿它们当混杂变量钉住或标注，不自己出它们的结论。
2. **标称配方不是比特预算。** `UD-Q4_K_XL` 是配方名；每份文件的比特预算只认 gguf 头的实测值（数据段位宽与文件位宽互校，差 >0.05 打 WARN）。库里 7 对 QAT/原生对**没有一对**比特预算相同（差 0.359–0.953 比特/权重），所以任何不写「按实测比特归一」的差值句都是把两个变量当了一个。
3. **比 QAT 与原生之前先比张量清单（图结构）。** 两个 gguf 的张量名集合（含每张量的元素数）不相等时，它们**不是同一张图**，差里就多了一个「图结构」变量。本库的四对 E 系列配对正是这样：E2B 的 QAT 缺 60 个张量（`attn_k`/`attn_k_norm`/`attn_v` × 层 15–34，参数 −18.88 M），E4B 缺 54 个（× 层 24–41，−55.06 M）；12B/26B-A4B/31B 缺 0。清单不一致的对只能登记数字，**不得写进结论**。
4. **比 QAT 与原生之前先比格式与分配。** 这批 QAT 文件是 Q4_0 系（`general.file_type=2`，装权重的桶全 4.500 比特/参数），原生对照是 K 系混合（12B：embed 5.500 / attn 4.814 / ffn-dense 4.905；E2B 的 `other` 5.866）。所以一对可以同时在四点上不同：比特预算、分配轮廓、量化格式、图结构。a03 判「同字节下方案效应在 0.10–0.49 内不可分辨」，这句话是本轴残差的上界，不是本轴能绕过的许可。
5. **分配轮廓必须按全部装权重的桶读，包括 `other`。** E 系列的 `other` 就是 `per_layer_token_embd`（2.35 G 参数）+ 每层 `inp_gate`/`proj`，占 E2B 参数的 51.6%、E4B 的 38.9%。漏掉它，「QAT 把 embedding 压到 2.06」就会从「`token_embd` 那一桶（8.7%）」被说成「整个 embedding」，而 E4B 的实际分配是「压 `other` −2.81、抬 `ffn-dense` +1.51」。每个差都要给「Δ比特/参数 × 参数占比」的逐类贡献，且逐类之和必须回到实测 Δbpw（残差 <0.01）。
6. **配对只在一族内**：一族 = 去掉 `-qat` / `-it` / `-ud` 的血统根名（保留尺寸、大小写不敏感）。跨族同字节点不是受控比较。
7. **协议先验后比**：`protocol` 与 `n_items` 必须逐列相等（9 个基准的规范协议表由 `a03::analysis/pairs.py` 拥有，本层 import 不复制；区间来自 `a01::curves`）。不等就打印「不可比」，不进汇总。
8. **不池化**：基准、族、协议之间绝不平均；跨族只说「同号族数 + 逐族区间」并打印族数。
9. **区间用 a01 的 Newcombe method 10**：`truthfulqa_mc2` 的 `acc` 是概率质量（`i01::res26`），那一列只报差值不套二项区间。区间是非配对的（逐题结果没落库），「跨 0」只能说测不出。
10. **12B 异常只用它自己那一族的原生阶梯判**：允许段内线性插值到 QAT 的实测比特，外推必须单独标；不许拿别的族或别的基准的斜率顶替，也不许用「12B 常识上应该多少」当判据。
11. **未测 ≠ 0**：没测写「未测」+ 原因 + 代价；报告里缺的一侧不画成 0 分、不画成空柱。
12. **单次运行**：所有配对都是单次运行，区间只含逐题二项项。库内 `m78`/`m119`、`m80`/`m121` 是同一文件同一协议的两次独立测量且逐格相同，这是「同输入重跑同结果」的旁证，不是跨 run 区间的替代。

## 数字纪律与装置

1. 每个数字后面跟证据路径与一条能被别人重跑的命令；跑不出来写「未测」和原因，不写 0、不写「估计」。
2. 所有数字由一条命令复算：`python3 "docs/subprojects/a09-量化感知训练 QAT/analysis/qat_pairs.py"`；它必须退出 0，缺输入（gguf / 夹具 / `bpw_map.json` / 库行）退出 2 且不算 PASS。改判据要同时改它。
   `A09_SELFTEST=1` 必须**真的做一次变异**（把夹具里 12B QAT 的 `bpw_file` 改到 5.949，整轮跑在改错的夹具上），并打印「变异被抓住的预期」后退出 1；若没有任何预期被抓住，它退出 2 并说明判定装置有洞——那种情况比数字错更严重。
3. `.scratch/originals/*` 已退役：那里的数只能标「不可复现」并写明原件已退役，不得当证据来源。
4. 复用 `.wrapup/mres/*` 的落盘产物前先确认 `run_tag`、`n`、协议串与 server 参数；不确定就当未知。
5. 结论必须指回 `PLAN.md` 的 AC 之一；说不清服务哪条的工作不做。

1. `import` 而不复制：区间与规范协议来自 `a01::curves`，gguf 头解析与分配轮廓来自 `a03::analysis/alloc.py`。它们改名时本层要**报错**，不许静默换口径。

3. **报告与表格归 i02**：不改 `make_report.py`、`mktables.py`、`report.html`；本层只提交「应写成什么 + 否证条件」，`report.html` 永远重新生成，不手改。
4. **GPU**：本轴额度 4% GPU / 3% CPU，且**当前不需要 GPU**（结论全部可由库 + gguf 头得到）。真要起服务，按 `docs/plan/subprojects.md` 的并发例外与 `memory.free` 实测判，占锁用 `bash .wrapup/gpu_locked.sh`，起服后断言 server 自报的 `n_slots`，不符即作废该次测量。
5. 不改别的 subproject 目录、不改 `docs/plan/subprojects.md`。
