# a10 第三方量化方案 — 本目录规则

本文件只写这个 subproject 自己的窄规则；通用法则在仓库根 `AGENTS.md` 与 `/home/z/vibe/AGENTS.md`，不在此复述。
里程碑、工作包、AC、判据与派工在 `PLAN.md`；已成立的事实与证据在 `RESULT.md`；复算装置在 `analysis/`。

## 这个轴的口径（违反一条，结论就作废）

1. **X 是「方案是不是第三方」，不是一个连续分数**。第三方 = 文件名带 `GSQ-RCO`；原生 = 同一族 unsloth `UD-` 配方。标签是类别变量，效应只能在「同族、同字节（或已知 Δbpw）、同协议」的比较里读。
2. **位宽缺口必须写出来，不许当 0**。本库**没有**与第三方档同字节的原生档，所以每一对都写成「第三方档位宽 → 最近原生档位宽，Δbpw = …」，并把 Δbpw 乘上位宽尺子（`a03::slopes`）得到的「缺口值多少分」与残差一起报。把 Δbpw 隐去就等于把不同字节的两次测量当成同字节。
3. **原生阶梯不单调，所以插值只是记账**。本族原生阶梯 2.878 → 3.850 → 4.173 上的段差在某些列是**负的**（`RESULT.md::ladder-own-step`）。所以「插值档」只能当参照，不能当预测；插值区间取被夹住两格区间的**并**，并在输出里明写「两个点给不出插值误差」。
4. **区间用 Newcombe method 10，`n` 取该格自己的 `n_items`**（`a01::curves` 是唯一 home）。TruthfulQA 的 `acc` 是概率质量均值（`i01::res26`），那一列只报差值。区间是**非配对**的（逐题结果没落库），因此「跨 0」写「不可分辨」，不写「相等」，也不写「没有差」。
5. **不池化**：9 列逐列报；100 题子集（`ifeval`/`gsm8k`/`arc_challenge`/`truthfulqa_mc2`）不与 164/378/912 题的格共用判据；语言、协议、基准之间绝不平均。**60 题的探针不与 161 题的 MultiPL-E 格可比**，本族的第三方档在 MultiPL-E 列上根本没有格 —— 那是「未测」。
6. **缺一侧就是「未测」**：第三方档有、原生档没有的列，差值是「未测」，不写 0。同理，盘上没有的 gguf、跑不成的命令，写「不可得」，不写 0。
7. **分配只从实测读**：逐张量比特来自 gguf 头（相邻张量 `offset` 之差 ÷ 元素数），复用 `a03::alloc` 的 `read_gguf` / `tensor_class` / `profile`，且必须校验 `Σ字节×8 ÷ Σ参数` 复现 `bpw_map.json`。**不查量化类型表、不按档位名推分配**。
8. **「同分配」必须逐张量证明**，不是比类平均。类平均相同可以掩盖逐张量互换；本层因此同时打印「不同的张量计数 / 总张量数」。
9. **承载断言的证据随仓库走**：`analysis/fixtures/a10_map.json` 冻结分数格、位宽、逐类与逐张量分配指纹；`build_fixture.py --check` 用本机源做漂移检查，**缺源退出 2**（不是 0）。
10. **单次运行 + 确定性地板**：本族每格一次运行；`i01` 的贪心地板是 0 道题，所以同输入重跑不是噪声来源；换文件就是换输入，`i01::res29` 的「未记录输入差可致 ±16/161」是本层的外部约束，任何小于它的差只能说「测不出」。

## 与 a01 / a03 / i01 / i02 的分工（别越界）

1. **区间与家族定义借 a01 的**（`newcombe_diff`/`wilson`/`family_of`），**分桶与 gguf 解析借 a03 的**（`read_gguf`/`tensor_class`/`profile`），都不复制。上游改名本层就报错，不静默换第二套口径。
2. **不重做 a03**：a03 已经判过「同字节下方案/厂商标签不可分辨、标签是分配的代理」。本层引用它当前提，接着做第三方方案的位置，不重新下它的结论。
3. **不做 a01 的位宽曲线、不做 a04 的层分配策略、不做 a09 的 QAT**：这些行只在需要当混杂变量或尺子时被引用。
4. **不读 `__size`**：`a02` 已判规模列不可信，参数量取 gguf 头的精确值。
5. **不改别的 subproject 目录、不改 `docs/plan/subprojects.md`、不改 `make_report.py`/`mktables.py`/`report.html`**（i02 拥有）。本层对 `mktables` 的解析结果只**报告**，不修。

## 数字纪律

1. 每个数字后面跟证据路径与一条能被别人重跑的命令，缺一不写。跑不出来写「未测」和原因，不写 0、不写「估计」。
2. `.scratch/originals/*` 已退役：迁移来的 `res13` 措辞以本层装置复算为准，复算不出来的部分按「撤回」处理并保留死因。
3. 复用 `.wrapup/mres/*` 的落盘产物前先确认 `run_tag`、`np`/`ctx`、协议串；不确定就当未知。本层比较**只**用同一个 `protocol` 串的行，且要求 `cmd.txt` 之间除 `-m` 路径外一致（`RESULT.md::protocol-identity`）。
4. 结论必须指回 `PLAN.md` 的 AC 之一（位置 / 标签存活 / 无匹配对读法）；说不清服务哪条的工作不做。

## 数据库与脚本

1. `experiments.sqlite` 本层**只读**（`sqlite3` 的 `mode=ro`）。本层不写库。
2. 本层脚本只放 `analysis/`，必须能被一条命令重跑并打印可核对的数字；`analysis/run_all.py` 的退出码就是结论（0 = 全部成立，1 = 有断言翻红，2 = 输入不可得）。
3. 不加载模型、不占 GPU。本层不需要 GPU；需要 GPU 的补测项写在 `PLAN.md` 的 GPU 队列并明确不买。
