## 里程碑：家族轴的第一条受控读法（`fam` 里程碑的 a15 部分）

- 终点状态：仓库里有一条命令，从 `experiments.sqlite` 枚举**全部**跨 `__model` 的受控对（同基准、同量化档、
  十六个身份栏全等、实测参数量相差 ≤10%），逐条给出家族差与区间、家族差随量化档的符号翻转、以及每个基准上的
  家族排序，并且每一处「测不出」写成测不出、每一个未匹配项带原因；两个负控各自能被打红。
- done 判据：`python3 "docs/subprojects/a15-模型家族/analysis/run_all.py" --selftest` 退出 0（清单、效应、
  两个负控、关系式自检、确定性断言全绿），且 `RESULT.md` 里每个数字后面都有一条能重跑的命令。
- 界外（写在这里以免越界）：本里程碑**不测**新格、不启模型、不改库、不改报告；「家族」= 架构 + 训练配方 +
  tokenizer 的整包，任何 Δ 只读成家族包效应。

## 未解问题

- 同权重不同架构 :: 要让「架构」与「家族包」分开，需要一对**同一份权重**分别以稠密与 MoE 形态存在的受控点。
  库里没有（a02 的 arch 节已逐条证伪），盘上也没有；本轮只能把差异记在「家族包」名下。要补需外部权重，
  不在本层预算内。
- 高档位上的家族排序 :: 可读的量化档基本只有相邻两档（Q2、Q3）。再往上一档，两家族的实测 bpw 差就超过
  半个档宽（`RESULT.md::res6` 的第二条混杂），于是「家族排序在 Q4/Q5 上会不会翻」在本轮**未测**，
  不是「不会翻」。要补只能靠同比特预算的新测量，本层不做。
- 单跑噪声 :: 每个受控格是一条（或若干条同分）run，Wilson 区间只覆盖抽样误差，不覆盖重测误差。
  i01 在确定性解码下测到逐题地板为 0 道题，但那是对特定 harness 的结论，不能直接搬到这些格上。
- 拆不开的三份 :: 架构、训练配方、tokenizer 在这份数据里永远同时变。本轮找到的唯一「半控」是同一份权重换
  量化配方（`LFM2.5 | LFM2.5-m55*`，a04 的臂）与同一份权重被两个 `__model` 标签拆开（`Qwen3.6 | Qwen_Qwen3.6`），
  它们给出 −10.32…+20.00 pp 的差（`RESULT.md::res6`）——这既说明配方能搬动分数，也说明「家族差」里有多少是配方，
  本轮**判不了**。
- agentic 基准上的家族差 :: BFCL 只有单轮五个类别构成跨家族受控对，多轮找不到跨家族对照（a13 的边界），
  agentic 基准本身无 GPU 不可测（`fam` 里程碑的 `agentic` 节）。
