## 判定口径（先写死，避免事后挑解释）

1. **策略 = 张量类别上的比特向量，不是标签名**。「均匀 / 专家优先 / 非专家优先」必须由实测轮廓按机械规则判出（见 `AGENTS.md` 第 1 条），档位名与厂商名都不是策略。
2. **受控比较的三条件**：同一套 base 权重（同族 + 同参数数）、协议串逐列相等（`protocol`/`n_items`/`ctx`/`np`/`temp`/`reasoning`）、**总有效位宽差落在写死的档内**。三档：`|Δbpw| ≤ 0.05`（钉住）/ `≤ 0.15` / `≤ 0.45`。每条结论必须写明它落在哪一档；跨档不一致就写「只在某档成立」。
3. **分配距离 = 参数加权 L1**：`L1_pw = Σ_c |b_c(A) − b_c(B)| · p_c / p_total`，单位比特/参数，量与 `Δbpw` 同单位、同一个量纲下才能比：`L1_pw ≈ |Δbpw|` 说明这一对基本只是「总比特变了」，`L1_pw ≫ |Δbpw|` 才是「总比特钉住了、比特挪了位置」。
4. **分数比较**：逐基准、Newcombe method 10、`n` 取该格自己的 `n_items`；TruthfulQA 的 `acc` 是概率质量均值，那一列只报差值（`i01::res26`）。
5. **禁止在 temp > 0 下做分配比较**：`i01::res32` 实测 temp=0.3 时同一格逐题 Jaccard 只有 0.53–0.67、而分数只摆动 6/164，即分数摆动系统性低估不稳定。本层所有格都是 greedy / temp 0，且 `i01::res32` 的地板是 0 题。
6. **不池化**：基准之间、语言之间、协议之间不平均；跨族只数同号族数并打印族数。
7. **未测 ≠ 0**：缺格写「缺」并写原因；没有钉住总比特的对照就写「语料里没有这个对照」，不写「没有效应」。
8. **承载断言的证据必须随仓库走**：已有轮廓只从 a03 的入库夹具 `docs/subprojects/a03-量化方案与厂商/analysis/fixtures/alloc_map.json` 读（只读，不改它）；`WP4` 新建配方的轮廓必须入库成 `analysis/fixtures/*.json` 并带漂移检查。
9. **预算尺子只作参照**：a03 的同族每比特斜率（HumanEval+ +0.1779、MMLU +0.1084、MBPP+ +0.1329）用来把 `Δbpw` 折成分数，判断「这个差能不能由比特预算解释」；它不是本层的测量，引用时必须写明来源是 `a03::slopes`。
10. **Tier-1A 的资源结论必须验尺寸**：写「需要 F16 源」时必须给在盘文件的实测字节数（`stat -Lc%s`，符号链接要 `-L`），不引 `plan6` 的 ~70 GB 而不验。
11. **钉住档的可行性先算再试**：专家桶在钉住约束下能挪多少有恒等式上界 `(1−s_exp)/s_exp × 层桶跨度`（`alloc_pairs.py --bounds`）；上界小于要试的跨度时，那个配置**不可能**被钉住，不得拿它当分配对照。
