# PPL / resolution report (T1 + T2)

_Companion to `PPL_JOIN.md` (generated by `ppl_analysis.py`). Question being answered:
**why does the study find ">= Q3 is enough" when local-deployment advice says Q4/Q5/Q6
and PPL keeps improving?**_

## Method

* PPL: `llama-perplexity -f <corpus> -c 2048 --chunks 40 -ngl 99 -ctk q8_0 -ctv q8_0`,
  identical flags at every point. Corpora in `.wrapup/ppl_corpora/`:
  `code_python`, `code_multi`, `nl_english` (~1.0–1.5 MB each).
* Reference scores: MultiPL-E pass@1 (greedy, raw completion) from `experiments.sqlite`,
  `bench_family='humaneval-multipl-e'`.
* Continuous metric (T2): per-test pass fraction over the same completions
  (`.wrapup/testfrac_summary.jsonl`).

## H1 / H4 — verdict: SUPPORTED (with one counterexample)

PPL keeps falling **above the level where pass@1 saturates**, for 4 of 5 anchors:

| anchor | quant | code_multi PPL | MultiPL-E pass@1 |
|---|---|---|---|
| Qwen3.5-2B | Q2 | 1.904 | 0.120 |
| | Q3 | 1.806 | 0.275 |
| | Q4 | 1.783 | 0.284 |
| | Q5 | **1.779** | 0.277 |
| Qwen3.5-4B | Q2 | 1.745 | 0.314 |
| | Q3 | 1.687 | 0.457 |
| | Q4 | 1.669 | — |
| | Q5 | **1.663** | — |
| Qwen3.5-0.8B | Q2 | 2.256 | 0.045 |
| | Q3 | 1.968 | 0.106 |
| | Q4 | 1.934 | — |
| | Q5 | **1.926** | — |
| granite-4.1-3b | Q2_K | 2.473 | 0.048 |
| | Q3_K_M | 2.053 | 0.391 |
| | Q4_K_M | **1.766** | — |

**Reading:** the extra quality above Q3 is real in the likelihood distribution but does not
appear as task success on short single-function synthesis. ">= Q3 is enough" is therefore a
statement about **what these benchmarks can measure**, not about model quality. Q4/Q5 are not
wasted; their benefit is orthogonal to this benchmark family (long-form coherence, instruction
following, rare-token robustness, general NL quality).

**Counterexample (PPL is not a quality proxy):** `gemma-4-E2B-it` has *worse* PPL at Q3 than Q2
on all three corpora (`code_python 4.117 -> 4.595`, `code_multi 3.107 -> 3.538`,
`nl_english 23.6 -> 29.2`) while pass@1 **doubles** (`0.2008 -> 0.4161`). Lower PPL and higher
capability can be anti-correlated for aggressive quants.

## H2 — verdict: REFUTED (metric resolution is not the cause)

The continuous per-test fraction does not separate Q3/Q4/Q5 either; it moves in lock-step with
binary pass@1. `Qwen3.5-2B` mean fraction cpp `0.431/0.408/0.435`, js `0.479/0.534/0.518`,
py `0.444/0.418/0.398` (1 SE ~ 0.039). So the saturation is **not** binary-metric coarseness.

## H3 — partially tested

Harder agentic coverage (BFCL `live_*`, multi-turn) is measured separately; see `m8_summary.jsonl`
and `LADDER_TOOLS.md`. The `live_*` categories are markedly harder than `simple_python`
(live_simple 0.221 vs simple_python 0.57 for the same model), which is the direction H3 predicts,
but the Q2/Q3 contrast there is still being collected.

## Open item

granite-4.1-3b has the **largest above-Q3 PPL drop** (Q3 2.053 -> Q4 1.766, -14%). Its pass@1 at
Q4 is the decisive test of whether ">= Q3" is universal or family-dependent; the run is queued
(`run_granite_q34.sh`). If Q3->Q4 pass@1 is flat despite a -14% PPL, saturation is confirmed
strongly; if it rises, the rule is model-dependent.
